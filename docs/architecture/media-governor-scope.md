# MediaGovernor 架构边界

## S1：兼容性验证

S1 的唯一目标是证实官方 MoviePilot V3 插件目录、索引和最小生命周期可以被宿主加载。它不进入媒体链路，不创建后台服务，不注册工作流动作，也不修改宿主数据。

## 后续阶段的通用目标

后续只考虑通用治理能力：识别置信度、命名冲突、文件集完整性、硬链接条件和异常分类。每个动作先输出可审计计划，再按“自动通过 / 可定向补救 / 需要人工确认”分类；不得针对单部影视作品写规则。

## 进入 S2 的硬前提

1. 真实 MoviePilot V3 宿主已加载 S1，且配置页和停止生命周期通过。
2. 已核验上游是否提供所需稳定事件、Chain 或 SDK；缺失时先在主仓提出宿主能力，而不是绕过内部 API。
3. 已定义预演、幂等、失败分类、回执与最小人工队列合同。
4. 获得用户对 NAS 安装、启用和任何媒体动作的单独授权。
