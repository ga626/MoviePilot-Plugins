# MediaGovernor：线索投影与只读判定边界局部收敛

日期：2026-11-07。范围：本地实现与回归；不是 NAS 识别验收报告。

## 结论与停止点

按用户认可的诊断结论实施局部修正，不更换主解析器、不接入新依赖、不启用 AI、不增加媒体写入能力。先修线索投影，再修精确预览与结论边界，最后冻结源码身份。

本次开发分支为 `codex/recognition-projection-boundary`，基线为 `53199c7df270b6fe70b23ad759506407422b10a9`。最终提交 SHA 与命令回执单独写入本地忽略目录，避免文档引用自身提交产生循环。

当前仍保留源码中的 5.1.3 元数据，表示尚未进入新版本交付阶段，**不得把本分支包作为已发布的 5.1.3 覆盖安装**。后续若获准进入交付，准备独立的 5.1.4 候选身份；版本元数据变化后重新绑定最终 SHA/制品。未推送、未建 PR、未公开发布、未替换 NAS 插件。

## 具体改变

### 1. 保留已有证据，不扩大模型输入

- SDK 返回的中文、英文和原名分别保留；真人版上下文单独保留。不再用 `cn_name or en_name` 把另一种语言丢掉。
- 移除“标题族数量不等于一就提前拒绝”的自动身份门槛；仍保留完整性、解析失败、结构歧义及证据预算保护。
- 同一文件的多语言名称作为备选线索；不同文件组则必须都能由同一数据库作品的可信别名解释。不是任意一个标题命中就接受整包。
- 数据库查询最多三次、详情最多三项；未用于查询的标题组仍参加详情核验，不因查询预算而丢弃。
- 真人版上下文参与查询及详情核验；动画或没有类型依据的详情不能自动消解该上下文。不从查询词、概述或任意括号文本制造可信别名。
- 保留 SDK 主路径和现有“至少两个同季 SDK 锚点、唯一标题前缀、无电影年份”的裸集号补充；没有新增 Anitopy，也没有按具体作品硬编码。

### 2. 精确选择正片，不用目录扩大范围兜底

- 仅当运行时公开签名显式声明 `selected_fileitems` 才使用集合预览；只有 `**kwargs` 不算能力证明。
- 旧宿主退到逐个精确文件预览，关闭附加文件同步；不退回整个目录预览。
- 官方返回必须恰好覆盖所选源文件。漏项、范围外文件、重复源、多个源指向同一目标均不能通过。
- 样片与附件不计入正片预览必需集合；未计划附件保留说明，不猜目标。本轮不宣称字幕、封面等附属文件的完整治理验收通过。
- 修正祖先目录名字含 `sample` 导致整个作品被排除的误判：父目录仅接受完整样片目录名，文件名仍使用原有样片标记规则。
- 没有可预览正片时明确 `no_supported_sources`，不再把零调用、零结果标为通过。

### 3. 作品身份、季集映射、执行许可分开

- 裸集号推断只在对应文件的只读预览里显式传入 `season` 和 `epformat.detail`，不写回作品身份，也不覆盖用户已有映射。
- 正片目标仍需核对季集。显式季号必须在官方目标上落地；仅仅传入选项不等于映射成功。
- offset/episode_group 的完整解释仍由官方执行，不自造另一套完整映射引擎；本地核对不是数据库全集完整性或下载完成证明。
- 自动补齐映射只用于本轮只读核对，生成修复计划及沿旧计划执行时均明确拒绝，避免识别层新增选项未传到写入层。

### 4. 收窄结论

| 观察 | 本轮结论边界 |
| --- | --- |
| 官方请求/summary 成功，但没有目标 | `preview_unresolved`，不是正常，也不是原生整理失败 |
| 目标完整，但季集映射未落地 | `mapping_confirmation`，作品身份与映射分开 |
| 预期入口缺失，但已证实另有硬链接 | 保留预期缺失事实，按已有证据报错链或路径偏差，不叠加“从未整理” |
| 硬链接 API 返回未证实/复制文件/读取异常 | 保持待确认，不升级为已关联 |
| 当前预期入口缺失且未发现已证实其他入口 | 沿用 `native_failure` 数据键兼容旧流程，但文案与证据明确仅为当前预期缺失，历史执行为 unknown |

最后一行不是“全库没有任何硬链接”的证明。现有存储枚举与严格空值语义仍有现场限制，不借本轮修改宣称已解决全部物理关系检索。

身份与预览策略修订号已更新，防止旧自动核验及目录范围预览缓存被直接当成本轮结果复用。人工身份不因策略变化被静默改写。

## 本地验证与测试桩边界

测试使用真实 SDK 解析、临时文件与硬链接，以及明确的假数据库、假官方预览；不调用真实 AI/数据库，不访问 NAS 媒体。

新增 `test_projection_boundary.py` 覆盖多语言、跨组同 ID、真人版类型冲突、查询预算但不丢证据、样片范围、空集合、越界/漏项/重复响应、旧宿主精确单文件、无目标成功、尾集显式映射、人工选项不覆盖、显式季号不落地、只读映射不能修复、其他已证实链接、复制未证实、签名能力与安全预览参数。

旧测试中“错链且预期缺失必须同时报原生失败”的期望已按用户要求调整，缺失事实仍单独断言。假适配器新增精确集合响应模拟；坏响应测试直接返回未经筛选的原始假响应，生产代码不会替官方过滤越界结果。

最终 `tests/v3/mediagovernor` 整套 **216 项通过，64.86 秒**；`compileall`、插件版本门禁与 `git diff --check` 均通过。前端源码、依赖与构建产物未改变。命令及冻结身份另见本地回执，不将这些数字称为 NAS 准确率。

## NAS 回归清单与未验风险

本轮只读浏览器检查确认 NAS 显示媒体治理 5.1.3，未执行插件安装、启用、重启或媒体修复。版本历史窗口本次未加载出条目；已查看插件菜单没有本地 ZIP 上传项。这不足以断言宿主所有渠道均不存在，但不能据此绕道 SSH、容器 Shell 或手工覆盖插件源码。

在同一最终候选实际加载并核对身份后，再对上一轮同批样本复跑，保持 AI 关闭、read_only 开启：

1. 中英文/别名：核对是否到达查库、是否归同一可信 ID、是否减少不必要确认；不能仅看候选数量变多。
2. 真人版与动画同名：检查上下文没有丢失，类型不足则保留未决，不强认。
3. 尾集裸数字：核对显式季集选项、官方有目标、目标对应尾集；不能只看 HTTP/summary 成功。
4. 正常电影、正常剧集、多季：检查原本正常项不被误报，完整源范围与逐文件关系可解释。
5. 已证实其他入口、预期缺失、关系未证实：分别核对，不把缺集、没链接、没查完混成一种失败。
6. 原盘：继续说明物理关系合同不支持；不转入原盘内部文件全库配对。
7. 对比同配置的任务是否完成、总墙钟与在途调用；旧宿主逐文件预览可能更慢，本轮不承诺性能提升、不加并发掩盖等待。

不改媒体造缺集，不删除文件，不清缓存冒充冷启动。没有候选安装身份与本轮现场回执时，真实回归状态只能是“未执行”。PR/CI、公开只读试用与安装回归的授权边界已一次性向用户提出，不挪用旧版本例外。
