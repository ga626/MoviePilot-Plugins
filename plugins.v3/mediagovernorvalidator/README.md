# 媒体治理验证台

`MediaGovernorValidator` 是 MediaGovernor 正式重构前的临时只读验证插件。它一次安装完成 V0-V8：宿主能力、下载器强边界、旧库存推定边界、文件守恒、AI 证据与批次消融、数据库候选、官方 preview、S/C/E 对账、隐藏答案回放以及停止/恢复/增量验证。

插件不会整理、重建、删除、移动、改名或创建硬链接。只有用户点击“运行全部只读验证”并确认脱敏字段与预计模型调用后，才会调用当前 MoviePilot 已配置的大模型。运行态存放于插件私有数据目录；报告不包含真实根路径、torrent hash、tracker、Cookie、下载器凭据或媒体内容。

该插件不是第二个长期产品。全部关键门通过后，稳定合同和脱敏测试会移植回正式 MediaGovernor，验证台随后退役。
