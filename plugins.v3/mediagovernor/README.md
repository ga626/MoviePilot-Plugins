# 媒体治理（MediaGovernor）

MoviePilot V3 的最后一道整理兜底。MoviePilot 仍是唯一执行整理、删除旧硬链接和重建新硬链接的主体；本插件只负责找出需要复核的包、给出作品候选，并调用官方预览。

## 检查什么

每次检查只处理两类来源：

1. 还没有同来源成功记录的失败整理；
2. 安装 2.1 后新发生的成功整理。

第二类会做整包模型核验，用来抓“表面成功、实际分错作品/目录/季集”的情况。它不递归扫描整个媒体库，不把旧历史条数当问题数；旧版事件不参与新范围，事件索引最多保留 400 条脱敏条目，历史详情每次重新向 MoviePilot 读取。

每个进入范围的包先读当前来源和当前硬链接目标，再按批把完整的脱敏名称/层级证据交给 MoviePilot 已配置模型。模型只提出身份假设；MoviePilot 的原生识别、数据源候选、年份/类型/集数交叉核验和用户确认共同决定是否可处理。

## 整理正确

确认作品后，页面依次调用 MoviePilot 的 `transfer/manual/history`、`transfer/manual/target-path` 和 `transfer/manual` 预览。预览完整才可由用户二次确认执行；最终仍由 MoviePilot 清理命中成功历史的旧媒体库硬链接，再从下载原文件重建。插件不调用 `storage/delete`，不会删除下载原文件。

## 边界

- 检查、候选和预览均为零写入；
- 模型只接收不含路径的名称、层级和数量证据；
- 事件监听只记录脱敏历史 ID、状态和标题线索，不读文件、不调用模型；
- 本地构建与合同测试不能替代真实 MoviePilot 加载、预览和用户安装验收。
