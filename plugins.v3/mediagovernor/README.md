# 媒体治理（MediaGovernor）

MediaGovernor 是 MoviePilot V3 整理失败后的最后一关。它不接管下载，也不替代 MoviePilot：页面只编排已经登录的 MoviePilot 官方 API，先恢复作品身份并让你看官方预览，确认后仍由 MoviePilot 建立硬链接。

## 使用方法

1. 在 MoviePilot 的“插件”中打开“媒体治理”。
2. 点击“开始检查全部”。它只读取失败整理历史、来源文件项和官方识别结果，不会改动文件。
3. 每个可确认作品会按来源包合并；没有可靠身份时，打开卡片并从 MoviePilot 的官方搜索候选中选择正确作品。
4. 点击“生成官方预览”。这一步固定使用 `preview=true`，不会创建、删除、移动、改名或覆盖文件。
5. 核对预览后点击“确认创建正确硬链接”。MoviePilot 才会按当前官方规则创建入口。

## 会检查什么

- MoviePilot 已记录为失败、且来源文件仍可读取的整理记录；
- 来源文件的官方作品识别；
- 同一来源包的视频、字幕数量摘要；
- 身份不唯一时最多三个官方搜索候选，以及官方预览是否接受该请求。

同一已确认作品的失败记录会合并在同一张卡片中。字幕和视频分别统计，但这个摘要不是“目标目录已完全正确”的证明。

## 安全边界

- 检查和官方预览均不创建、删除、移动、重命名或覆盖文件；
- 真正执行前必须经过 MoviePilot 官方预览和用户再次确认；
- 原始下载文件不会被本插件移动、改名或删除；
- 普通修复只传来源文件、不会传失败历史 ID；因此不会触发 MoviePilot 的“清理旧目标”分支；
- 插件不保存或展示媒体/下载路径、完整文件名、Cookie、订阅、代理、PT 信息或媒体内容；
- 插件不自动删除旧展示入口。涉及删除或覆盖的情况会停止在说明，不会隐藏在“一键修复”里。

## 已知限制

- 已显示为“整理成功”但分类、季集或文件集错误的历史，本版不会自动判定或清理；
- “源包本来缺少的剧集”不能靠重新整理补回；
- MoviePilot 的 AI 名称识别增强不是本插件的独立能力；本页使用宿主已提供的识别与搜索结果，不能读取或理解视频内容。

## 开发与发布

本插件遵守 MoviePilot V3 的 `plugins.v3/`、`tests/v3/` 和 `package.v3.json` 合同。提交候选时必须通过定向 Python 测试、前端构建、版本与联邦 CSS 门禁，并在真实 MoviePilot V3 宿主完成加载验证。
