# 媒体治理（MediaGovernor）

MediaGovernor 是 MoviePilot V3 的整理结果质检台。它不接管下载或整理，而是在整理完成或失败后，把同一作品的记录归成一张问题卡，说明哪些结果可信、哪些需要处理，以及为什么。

## 它会做什么

- 观察启用后发生的整理完成和失败事件；
- 按媒体身份合并记录，避免逐集刷出重复问题；
- 显示“已验证、需要处理、需要选择、等待宿主信息”四种状态；
- 对失败记录生成固定为硬链接的**零写入预演计划**；
- 保存脱敏状态、原因和计划回执，方便复查。

## 它不会做什么

- 不移动、改名、删除、重试、覆盖或创建硬链接；
- 不修改下载器、代理、下载目录或 MoviePilot 的原生整理规则；
- 不读取或展示媒体路径、下载路径、Cookie、令牌、PT 链接或完整文件列表；
- 不为某一部作品写专属规则，也不会在身份有歧义时擅自猜测。

## 开始使用

1. 从 MoviePilot 插件市场安装并启用本插件。
2. 打开 MoviePilot 的“插件”，点击“媒体治理”卡片进入问题台。这个入口兼容新旧 MoviePilot V3；首次没有新整理事件时，页面会显示为空，这是正常的。
3. 新整理事件出现后，查看问题卡的状态和原因。
4. 对失败记录点击“查看硬链接预演”。每张问题卡会保留最近一次结果：能继续时显示零写入计划；不能继续时说明是缺少历史信息还是 MoviePilot 未能生成安全方案。这只生成计划，不会改动任何文件。

### 状态说明

| 状态 | 含义 | 建议 |
| --- | --- | --- |
| 已验证 | 已取得的公开记录彼此一致 | 无需操作；这不代表媒体服务器的最终展示已被验证。 |
| 需要处理 | 原生记录失败，或出现可证明的不一致 | 查看原因并生成预演计划。 |
| 需要选择 | 存在身份冲突，程序不能可靠判断正确结果 | 先由用户确认正确身份；插件不会自动选择。 |
| 等待宿主信息 | 当前 MoviePilot 未提供足够的公开字段 | 无需反复尝试；等待宿主能力补齐或人工核对。 |

## 隐私与安全

插件只保存媒体身份、状态、计数、原因码和不可反推文件位置的指纹。用于预演的临时文件信息不会持久化，也不会通过 API 返回。所有 API 均使用 MoviePilot 的 bearer 认证，并始终限定在当前插件实例范围内。

旧失败记录回溯默认关闭。若用户主动开启，它只读取一次；完成或发现宿主不支持后会自动停止，不会周期性重扫历史。

## 开发与发布

本插件遵循 MoviePilot V3 的 `plugins.v3/`、`tests/v3/` 和 `package.v3.json` 合同。复杂交互使用官方 Vue 模块联邦；构建产物位于 `dist/assets/`。提交前至少运行定向 Python 测试、前端构建、版本门禁和真实 V3 宿主加载验证。
