# 媒体治理（MediaGovernor）

MediaGovernor 是 MoviePilot V3 的整理问题台。它不接管下载或整理，而是把 MoviePilot 已记录的整理异常整理成中文问题卡，让用户先看懂“哪部作品、出了什么问题、下一步怎么做”，再决定是否确认处理。

## 它会做什么

- 观察启用后发生的整理完成和失败事件；
- 按媒体身份合并记录，避免逐集刷出重复问题；
- 用“整理没有完成、影片尚未识别、作品信息有冲突、缺少整理信息”等中文类型说明问题；
- 没有可靠媒体身份时明确显示“待确认影片”，不会把原始英文名或乱码假装成中文片名；
- 对失败记录做一次不改文件的“模拟检查”；
- 只有模拟检查通过、未过期的单条计划，才允许用户在页面二次确认后创建硬链接；新的检查失败会自动作废旧计划，绝不把旧结果当成当前可执行操作；
- 保存脱敏状态、原因和计划回执，方便复查。

## 它不会做什么

- 不移动、改名、删除、重试或覆盖文件；硬链接只会在模拟检查通过且用户二次确认的单条计划中创建；
- 不修改下载器、代理、下载目录或 MoviePilot 的原生整理规则；
- 不读取或展示媒体路径、下载路径、Cookie、令牌、PT 链接或完整文件列表；
- 不为某一部作品写专属规则，也不会在身份有歧义时擅自猜测。

## 开始使用

1. 从 MoviePilot 插件市场安装并启用本插件。
2. 打开 MoviePilot 的“插件”，点击“媒体治理”卡片进入问题台。这个入口兼容新旧 MoviePilot V3；首次没有新整理事件时，页面会显示为空，这是正常的。
3. 新整理事件出现后，先看问题卡的中文问题类型与作品名称。
4. 点击“查看并核对”，阅读这是什么问题、当前建议和下一步。
5. 点击“模拟检查，不改文件”。它只检查 MoviePilot 现在能否生成安全方案，不会改动任何文件。
6. 只有检查通过才会出现“确认创建硬链接”。点击后会再弹出确认窗口；修复只创建硬链接，不删除、覆盖、移动或改名文件。
7. 检查不能通过时，按弹窗中的三步人工处理说明到 MoviePilot 的搜索结果、整理或历史记录核对；确认仍未入库后再回到问题台检查。

### 状态说明

| 状态 | 含义 | 建议 |
| --- | --- | --- |
| 已验证 | 已取得的公开记录彼此一致 | 无需操作；这不代表媒体服务器的最终展示已被验证。 |
| 需要处理 | 原生记录失败，或出现可证明的不一致 | 打开问题卡，先做模拟检查。 |
| 需要选择 | 存在身份冲突，程序不能可靠判断正确结果 | 先由用户确认正确身份；插件不会自动选择。 |
| 等待宿主信息 | 当前 MoviePilot 未提供足够的公开字段 | 不要反复点击；按人工处理说明核对。 |

## 隐私与安全

插件只保存媒体身份、状态、计数、问题原因和不可反推文件位置的指纹。用于模拟检查的临时文件信息不会持久化，也不会通过 API 返回。所有 API 均使用 MoviePilot 的 bearer 认证，并始终限定在当前插件实例范围内。

旧失败记录回溯默认关闭。若用户主动开启，它只读取一次；完成或发现宿主不支持后会自动停止，不会周期性重扫历史。

## 开发与发布

本插件遵循 MoviePilot V3 的 `plugins.v3/`、`tests/v3/` 和 `package.v3.json` 合同。复杂交互使用官方 Vue 模块联邦；构建产物位于 `dist/assets/`。提交前至少运行定向 Python 测试、前端构建、版本门禁和真实 V3 宿主加载验证。
