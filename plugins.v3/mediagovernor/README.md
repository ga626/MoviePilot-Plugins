# 媒体治理（MediaGovernor）

MediaGovernor 是 MoviePilot V3 的整理检查工具。它不接管下载或整理，而是把 MoviePilot 已记录的历史异常一次查清，再把确实需要处理的结果用中文展示出来。

## 它怎样工作

1. 在 MoviePilot 的“插件”中打开“媒体治理”。
2. 点击“**一键检查全部（不改文件）**”。
3. 插件会对每条历史失败记录依次执行三件事：
   - 使用 MoviePilot 当前的原生识别链，尝试确定作品名称、年份和类型；
   - 使用 MoviePilot 的硬链接预演，确认现在能否安全处理；
   - 只保存检查结论，不保存原始文件名或路径。
4. 检查完成后，页面只显示仍需处理的项目：
   - **可以处理**：已识别作品，且可以安全创建硬链接；
   - **暂不能处理**：已识别作品，但当前不能安全创建硬链接；
   - **无法自动识别**：历史记录不足，不能可靠确定作品身份。
5. 对“可以处理”的项目，先生成处理方案，再由用户确认。确认后只创建硬链接。

检查会读取 MoviePilot 的历史记录，并可能使用你已经配置好的媒体识别来源或辅助识别能力补齐作品身份；它不会下载影片、修改下载器、代理或原有整理规则，也不会移动、删除、改名、覆盖或创建媒体文件。

## 为什么先检查、后展示

历史失败记录只能说明“当时有异常”，并不等于现在仍然有问题。插件会先把每条记录核查一遍：能确认已经不需要处理的记录不会变成卡片；无法可靠识别或确实不能安全处理的记录才会交给用户。

## 无法自动处理时

点击卡片中的“查看结论”，再展开“仍无法处理？查看人工步骤”：

1. 在 MoviePilot 搜索页确认作品、年份和类型。
2. 在整理或历史记录中确认它是否已经入库；已入库就无需处理。
3. 若仍未入库，修正可识别的名称后，再回到本插件重新执行一键检查。

## 安全边界

- 不移动、改名、删除、重试或覆盖文件；
- 不修改下载器、代理、下载目录或 MoviePilot 原生整理规则；
- 不保存或返回媒体路径、下载路径、Cookie、令牌、PT 链接或完整文件列表；
- 不为某一部作品写专属规则；身份不可靠时不会猜测。

硬链接只会在单条记录已通过模拟检查、并由用户在确认窗口再次确认后创建。新的模拟检查结果会作废旧的待执行方案，避免旧状态被误用。

## 开发与发布

本插件遵循 MoviePilot V3 的 `plugins.v3/`、`tests/v3/` 和 `package.v3.json` 合同。复杂交互使用官方 Vue 模块联邦，构建产物位于 `dist/assets/`。提交前至少运行定向 Python 测试、前端构建、版本门禁和真实 V3 宿主加载验证。
